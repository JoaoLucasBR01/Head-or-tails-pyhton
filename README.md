# Heads or Tails 🪙

This is a small Heads or Tails game I made while learning Python. It's one of my first programming projects.

The idea is pretty simple: you choose heads or tails, and the computer flips a coin. The game keeps track of how many times you win or lose.

## How the game works

1. Choose how many rounds you want to play.
2. Type `0` for Heads or `1` for Tails.
3. The computer randomly chooses Heads or Tails.
4. See if you won that round and make your next guess.
5. At the end, the game shows your wins, losses, and the final result.

## How to run it

You need Python 3 installed on your computer.

1. Download the file `cara_ou_coroa.py`.
2. Open a terminal in the folder where you saved it.
3. Type:

   ```bash
   python cara_ou_coroa.py
   ```

If that doesn't work, try `python3 cara_ou_coroa.py`.
